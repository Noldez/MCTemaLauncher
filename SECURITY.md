# Security Policy

## Supported versions

Only the latest release is supported. The launcher updates itself automatically.

## Reporting a vulnerability

Please report vulnerabilities privately - do not open a public issue.

- GitHub: use [private vulnerability reporting](https://github.com/Noldez/MCTemaLauncher/security/advisories/new)
- Discord: message `noldez`

You will get a response within a few days. Please include steps to reproduce and affected version.

## Scope

This repository covers the desktop launcher only. Server-side issues (mctema.lt APIs, game server) are also welcome through the same private channels.
