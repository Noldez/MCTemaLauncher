# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, no harassment, no personal attacks, keep discussions about the project. The same rules as on the MC Tema server and Discord apply here.

Violations can be reported privately to `noldez` on Discord or through the [MC Tema Discord](https://discord.gg/mctema) staff. Maintainers may remove comments, close threads or ban repeat offenders.
